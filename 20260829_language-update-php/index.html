PHPのライセンス変更

  • いままでPHPはApache-1.0派生の独自ライセンスだった
  • 一般的な寛容な自由ソフトウェアライセンスの条件は満たしているが、

OSIの承認を得られていないので微妙に使いにくいものだった

  • PHP 8.6からは修正BSDライセンス(BSD-3-Clause)に変更された
  • “PHP License 4”としてBSDLの文面を指定することで、

PHP License 3.0のアップデート条項を適用して軟着陸した

True-Async

  • シングルスレッドで動くPHPに「真の非同期」を入れようぜというプロジェクト
  • 全てのPHP関数は基本的に全てI/Oでブロックする
  • What Color is Your Function? 問題
  • よくある言語では Promise や async/await で非同期処理
  • True-AsyncではGoroutineに近い方法で処理できるように
  • PHP 9.0とかで入るといいなあ…
