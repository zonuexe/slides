型なしとはどういう状態か

  • ある式の値の型が静的に定まっていない (mixed, TSのunknown/any)
  • 型付けされた関数に渡したときに要求された文脈に従っているか
    (関数呼び出しをしたときにTypeErrorが出ないか安全だと言いきれない)
  • PHPではいろんなところから型なしが吹き出す
    • スーパーグローバル、eval、json_decode()、unserialize ()、
      PDOStatement::fetch()
