クロージャを使えばできる

<?php
$fizzbuzz = [];
foreach (range(1, 100) as $n) {
$s = '';
if ($n % 3 === 0) $s .= 'Fizz'; if ($n % 5 === 0) $s .= 'Buzz';
$s = ($s === '') ? (string)$n : $s;

$fizzbuzz[$n] = function () use ($s) {
return $s;
};
}

クロージャを使った部分適用
